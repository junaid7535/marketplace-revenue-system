# Marketplace Revenue Optimization

## 📊 Project Overview
Created an ML model to predict high-conversion marketplace products using pricing and rating features. Applied pricing and rating features to improve model performance by ~12–15% over baseline. Evaluated multiple machine learning models to predict high-conversion products with ~80–85% accuracy. Compared model performance using business-focused metrics (AUC 0.78+, precision 0.81).

## 🚀 Features
- **Predictive Modeling**: ML models to identify high-conversion products
- **Feature Engineering**: Advanced pricing and rating feature transformations
- **Business Metrics**: Focus on revenue-impacting KPIs
- **Modular Design**: Clean, maintainable code structure
- **Comprehensive Evaluation**: Multiple model comparison with cross-validation
